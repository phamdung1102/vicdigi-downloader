# Andrew Downloader Browser Extension

## Cài trên Chrome hoặc Edge

1. Cài Andrew Downloader bản mới nhất và mở ứng dụng một lần.
2. Mở `chrome://extensions` hoặc `edge://extensions`.
3. Bật **Chế độ dành cho nhà phát triển**.
4. Chọn **Tải tiện ích đã giải nén**.
5. Chọn thư mục `browser-extension`.

Sau đó dùng nút extension hoặc menu chuột phải **Mở bằng Andrew Downloader**.
